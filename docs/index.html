How it works

A menu-bar app (🎙️) listens for your shortcut. Everything below happens locally, in about a second for a short phrase on Apple Silicon.

1 · Listen
Hold the shortcut A glass pill appears above the Dock and the bars move with your voice. Double-tap for hands-free.
2 · Transcribe
Whisper, on-device Voice detection trims silence; faster-whisper detects Spanish or English and transcribes. It never translates.
3 · Clean up
Offline rules Drops “um / eh”, honors “scratch that”, “new line”, “2, no, 3”, and applies your dictionary & snippets.
4 · Fit in
Reads the cursor Adds the right space and capital, drops a mid-line period, skips password fields.
5 · Insert
Pastes at the cursor Accents land perfectly, and your clipboard (images, files, rich text) is put back afterwards.
You say“Um, the meeting is tomorrow at 2, no, at 3. New line. Please confirm.”
→
It typesThe meeting is tomorrow at 3.
Please confirm.

Features

The Wispr Flow experience, rebuilt to work offline.

🎙️

Smart shortcut

Hold to talk, double-tap for hands-free, and a lone accidental tap is ignored. Toggle and hold-only modes too. Works with Fn 🌐.

⎋

Cancel & recover

Esc cancels and ⌃⌘V pastes the last transcript again. If the shortcut turns out to be part of another one, the recording is dropped.

🧹

Offline cleanup

Filler words, stutters, “scratch that / borra eso”, “new line / nueva línea”, “punto y aparte”, and corrections like “at 2, actually 3”.

🤖

Optional AI cleanup

On macOS 26+ with Apple Intelligence, Apple's on-device model can fix grammar and format spoken lists. Still offline, and it falls back safely if it can't help.

📖

Dictionary & snippets

Teach it names and jargon, fix words it keeps mishearing, and say a trigger to insert saved text. It reloads as soon as you save — no restart.

🧭

Context-aware

Reads a few characters around the cursor to match spacing and capitals, and drops the final period in chat apps.

🌎

Bilingual

Auto-detect limited to the languages you speak (Spanish + English by default), so short phrases don't come out as Portuguese.

📋

Clipboard-safe

Your copied images, files or rich text survive a dictation, and clipboard managers don't record it.

🧾

History & stats

Recent dictations in the menu (stored only on your Mac, and you can turn that off), words today and your words per minute.

🎚️

Any microphone

Picks up mics as you plug them in and warns you if the mic is silent. Optional mute of other audio, sound cues, and sessions up to 20 minutes.

Install

There is no prebuilt download yet (a notarized .dmg needs an Apple Developer ID). Building it yourself takes about five minutes.

Requirements

  • macOS 11+ on Apple Silicon or Intel
  • Python 3.12+ — brew install python@3.13
  • Xcode Command Line Tools — xcode-select --install
  • ~500 MB free for the speech model (downloaded once)

No ffmpeg or Homebrew audio libraries needed — they ship inside the Python wheels.

Build & run

git clone https://github.com/jofer95/whisper-dictation.git
cd whisper-dictation
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

./scripts/build.sh
cp -R "dist/Whisper Dictation.app" /Applications/
open "/Applications/Whisper Dictation.app"

First launch

  1. build.sh asks for your login password once to create a local code-signing identity, so macOS remembers your permissions across rebuilds.
  2. Grant Microphone and Accessibility in System Settings → Privacy & Security. The menu item Grant / re-check permissions… opens the right pane.
  3. The speech model downloads in the background (the menu shows ⏳). After that, everything works without internet.

Want to ship a signed build to other Macs? DISTRIBUTION.md walks through the Developer ID certificate, notarization and scripts/release.sh.

Privacy

The only network access is the one-time model download from Hugging Face. After that you can unplug the Wi-Fi.

🔒

Audio stays local

Transcription runs on your CPU. Recordings are never written to disk or uploaded.

🚫

No accounts, no telemetry

No analytics or crash reporting, and no network code beyond the model download.

👁️

Minimal context

Context awareness reads only a few characters around the cursor via Accessibility, and nothing is kept after the dictation. Password fields are never touched.

🗂️

Your data, your Mac

Settings, dictionary, optional history and stats live in ~/Library/Application Support/whisper-dictation/.

Architecture

Python + PyObjC, packaged with py2app. One rule keeps it smooth: the main thread (menu, pill, shortcut tap) never blocks; a single serial audio worker opens the mic, transcribes and pastes, in order.

app.py

Menu-bar app (rumps), recording state, the serial audio worker.

hotkey.py

Quartz event tap that swallows the combo, plus a pure, unit-tested state machine for hold, double-tap and cancel.

recorder.py

16 kHz mono capture (sounddevice / PortAudio), mics tracked by name and re-scanned live.

transcriber.py

faster-whisper with VAD, restricted language detection that reuses the encoder pass, a hallucination filter and the vocabulary prompt.

textproc.py

Rule-based cleanup: commands, backtrack, fillers, dictionary, snippets, context rules.

aicleanup.py

Optional Apple Foundation Models pass through a Swift helper, with a strict timeout and fallback.

context.py

Accessibility: the focused app, field type, and the text before and after the cursor.

injector.py

Clipboard paste with a full snapshot and restore, a transient pasteboard type, and a raw ⌘V event.

overlay.py

The floating pill: waveform, spinner and short messages, on the screen under the mouse.

store.py

Dictionary (hot reload), history, and stats — all local JSON.

FAQ

Pressing Fn opens the emoji picker.

Set System Settings → Keyboard → “Press 🌐 key to” → Do Nothing. The app detects this and reminds you.

A word keeps coming out wrong.

Open Dictionary & snippets… and add the right spelling to words, plus what it heard to corrections (for example "rit me": "README"). It applies from your next dictation.

Spacing or capitals aren't adjusted in Slack / Teams.

Many Electron apps don't expose the text around the cursor through Accessibility. Dictation still works; only the context tweaks are skipped.

Nothing gets typed.

Check the Permissions line in the menu (Accessibility and Microphone should both be ✅). If no text field was focused, the text is left on your clipboard and ⌃⌘V pastes it again.

Can I make it more accurate?

Switch Speech model to Large v3 Turbo (a 1.6 GB download, slower on CPU), and add your names and jargon to the dictionary.

Does it work on Windows or Linux?

No — it relies on macOS APIs (Accessibility, Quartz event taps, AppKit).
